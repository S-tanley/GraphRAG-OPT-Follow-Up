# Report：实验 3，结构化连接能补回多少

*Bowen · 2026-10-15 · 对应 plan v2 §7 实验 3*

## 一句话结论

**免训练的手段补不回来；在 mask 下做 LoRA 能补回来。** 免训练时，只给顶部几层开放跨路径 attention 没有用，要从第 8 层左右开始放开（top-24 及以上）才行，可复用的层只剩 12–25%；sibling 组反而更差。而在 M2-hyb mask 下用 train split 做一个 epoch 的 LoRA 之后，**LoRA-M2 + M2-hyb 与"最佳全 attention"方案（LoRA-M0 + M0）在 cap 8/30 × CWQ/WEB 四组上的差距只有 −0.6 到 −1.0 个点，全部不显著**，路径 token 只有对方的 31–44%，KV 可以完全跨 query 复用。对照组 LoRA-M0 证明，这不是"多训练一轮"的效果：只做普通微调时，mask 带来的损失依然存在（−3.0 到 −6.4）。

## 设置

和实验 2 相同：引擎一致，CWQ/WEB 各 500 题，cap=8，RoG 和 Llama-2-7B。

- **M2-hyb+top-ℓ**：下面 L−ℓ 层用 trie mask；最上面 ℓ 层的路径 token 按去重布局做 causal attention（读取时使用紧凑位置）。L=32。
- **M1-hyb+top-ℓ**：同样的做法用在 GraphRAG-Opt 的 reuse-all 上，即"按层重算"。
- **M2-hybS / M2-parS**：每个 token 额外可以看到"最近的分叉祖先之下、布局中更早的所有 token"，也就是同一 (head, rel) 下的兄弟路径彼此可见。

**数值验证**：top-8 只改变最上面 7 层的路径 K（这符合预期：第 l 层的 K 是在该层 attention 之前计算的），首 token 的概率变化 ≤1%。所以 top-4/8 的结果和 M2-hyb 几乎完全一样，并不是 bug。

## 结论（免训练部分）

1. **跨路径整合发生在前中层。** top-ℓ 曲线在 ℓ ≤ 20 时几乎是平的，在 ℓ = 24 处明显回升，ℓ = 28 时已经在噪声范围内。对应到层：路径之间需要在大约第 8–16 层互相可见。在顶层补救，就像 CacheBlend 在 token 层面补救一样，作用不大。
2. **因此，按层分配复用的空间很小。** 要恢复准确率，只能复用底部 4–8 层，路径 KV 的复用比例只有 12–25%。再结合实验 4 的结果（"T + 现成前缀缓存"与 M2 节点级复用只差 5–8 个百分点的 token），免训练的 mask 方案在系统层面缺少足够的收益。
3. **"top32" 是一个有用的参照**：全部层都在去重布局上做 causal（没有大括号等文本标记），结果和 M0 持平（−1.8 到 +0.2，均不显著）。可见只做 token 级去重就足够，不一定需要 T 那样的文本格式。
4. **sibling 组的结果有混杂因素，暂不下结论。**（2026-10-16 更正）S 的结果比 M2 更差（Llama-2 WEB −15.2）。原先的解释是"不完整的跨路径上下文会误导模型"，但更可能的原因是**位置冲突**：M2-hyb 和 M2-par 的内部位置按深度编号，同一父节点下的兄弟分支共用同一段位置编号。互相看不见时这没有问题，一旦放开兄弟之间的可见性，模型就会看到位置相同、内容不同的 token，这是训练中从未出现过的输入。因此 S 实际上同时改变了"可见性"和"位置冲突"两件事，不能把结果归因于兄弟互看本身。待办：给 S 改用按布局顺序的内部位置后重测。
5. **GraphRAG-Opt 加按层重算同样无效**（top4/8 与 reuse-all 持平），这和实验 0 中 CacheBlend/EPIC 按 token 重算无效的结论一致：在 KG 路径上，损失不是靠局部修补能挽回的。

## LoRA（补救手段 4）

### 设置

- **模型与 LoRA**：RoG + LoRA（r=16，α=32，dropout 0.05，作用于 q/k/v/o，共 16.8M 参数）；bf16；lr 1e-4（20 步 warmup 后线性衰减）；梯度累积 8；1 个 epoch，735 步。
- **训练数据**：只用 train split，共 5882 题（CWQ 3167 + WebQSP 2715），已排除与测试集重复的问题。路径做法参考 RoG 自己的训练监督：取 q→a 最短路径的关系序列作为 relation plan，再用 RoG 的 `bfs_with_rule` 落地，cap=8。每题路径数 CWQ 6.6、WebQSP 5.1，和测试集（7.1 / 6.3）接近。目标是最多 5 个答案，以换行分隔，结尾加 EOS。脚本：`experiments/exp3/{build_train_paths,train_lora}.py`。
- **训练时的前向**与推理时完全一致：路径区使用条件的 mask 和 `pos_int`，问题与答案读取路径时使用 `pos_out`。
- **两个版本**：LoRA-M2（在 M2-hyb mask 下训练），LoRA-M0（同样的数据，在普通 causal mask 下训练，作为对照）。
- 两个版本的最终训练 loss 分别是 0.223 / 0.209，在单张 H200 上（与其他任务共享）各需约 17–19 分钟。
- **评测**：同样的 500 题；cap 8 和 cap 30。

### 结果一：同一个模型内部，相对它自己的 M0（ΔHit；* 表示 p<0.05）

| 模型 | 推理条件 | CWQ cap8 | WEB cap8 | CWQ cap30 | WEB cap30 |
|---|---|---|---|---|---|
| base | M0（Hit） | 0.508 | 0.754 | 0.576 | 0.798 |
| base | T / M2-hyb | +0.8 / −3.4* | +0.6 / −3.0* | −0.4 / −8.6* | +0.4 / −7.2* |
| LoRA-M0 | M0（Hit） | 0.536 | 0.794 | 0.572 | 0.818 |
| LoRA-M0 | T / M2-hyb | −0.4 / −3.0 | +0.2 / −4.0* | +0.2 / −6.4* | +0.6 / −5.4* |
| LoRA-M2 | M0（Hit） | 0.546 | 0.782 | **0.596** | **0.830** |
| LoRA-M2 | T / M2-hyb | −1.2 / **−1.8** | +1.8 / **+0.6** | −0.4 / **−3.4*** | +0.4 / **−2.2** |

cap=8 时 LoRA-M2 还会顺带修好 M1-hyb（GraphRAG-Opt reuse-all）：CWQ 0.522、WEB 0.788，相对自身 M0 分别 −2.4 和 +0.6，均不显著。

### 结果二：两种"最佳"方案的配对比较（基线：LoRA-M0 + M0）

| 方案 | CWQ cap8 | WEB cap8 | CWQ cap30 | WEB cap30 | 路径 token（cap8 / cap30，CWQ） |
|---|---|---|---|---|---|
| LoRA-M0 + M0（基线） | 0.536 | 0.794 | 0.572 | 0.818 | 222 / 702 |
| LoRA-M0 + T | −0.4 | +0.2 | +0.2 | +0.6 | 100 / 254 |
| **LoRA-M2 + M2-hyb** | **−0.8** | **−0.6** | **−1.0** | **−1.0** | **90 / 219** |

以上差异全部不显著（p ≥ 0.44）。原始输出见 `outputs/exp3/lora_compare.txt`。

### 结论（LoRA）

1. **mask 带来的损失可以靠训练消除，而且确实是 mask 适应的作用。** LoRA-M0（只做普通微调）在 M2-hyb 下仍然掉 3–6 个点；LoRA-M2 把损失降到 −1.8 到 +0.6（cap8，均不显著）。
2. **以"最佳全 attention 方案"为基线，LoRA-M2 + M2-hyb 在四组上都在噪声范围内**，同时路径 token 只有基线的 31–44%，KV 可以完全跨 query 复用，路径之间 prefill 可以并行。
3. **需要如实说明的残余差距**：LoRA-M2 在全 attention（M0）下推理是所有组合里最好的（cap30：0.596 / 0.830）。如果拿这个作基线，同一模型用 M2-hyb 在 cap30 CWQ 上仍差 3.4 个点（p=0.04），WEB 差 2.2 个点（不显著）。也就是说，在路径很多时，"最好的模型 + 全 attention"仍然略强。
4. **一个意外的副产品**：在 mask 下训练的 LoRA，用全 attention 推理时反而比普通微调更好（cap30：0.596 vs 0.572，0.830 vs 0.818）。可能是 mask 训练起到了正则化作用，迫使模型更多依靠问题 token 去整合证据。这一点需要用多个 seed 和全量数据确认，再决定能不能写进论文。
5. **局限**：只训练了 RoG；只有一个 seed、一个 epoch；评测只有 500 题。T 在 LoRA 下同样和 M0 持平，所以 T 仍然是最简单的方案；M2 相对 T 的独有价值依旧在系统层面（见实验 4 结果三）。
